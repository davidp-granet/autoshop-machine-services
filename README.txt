AutoShop Machine Services — single-page responsive website

Files:
- index.html       Main single-page website
- styles.css       Responsive styling and business-card-inspired visual design
- script.js        Mobile hamburger menu + demo form behavior
- assets/turbo-mark.png  Cropped turbocharger graphic from the supplied business card

To preview locally:
1. Put all files in the same folder.
2. Open index.html directly in a browser, or serve the folder with a simple HTTP server.

Python example:
  python -m http.server 8000
Then open:
  http://localhost:8000

The contact form intentionally does not send anywhere yet.
